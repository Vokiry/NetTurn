# NetTurn

> **Высокопроизводительный кроссплатформенный туннель следующего поколения через распределённую WebRTC TURN-инфраструктуру VK Calls.**

NetTurn объединяет лучшие архитектурные находки и UX-решения проектов **WDTT** (*amurcanov*), **qWDTT** (*SpaceNeuroX*), **VK TURN Proxy Desktop / FWDTT** (*mayitnick*) и **FFWDTT** (*ELKAPY*) в единое, быстрое, отказоустойчивое решение с безупречным пользовательским интерфейсом.

## 🔍 Обзор и происхождение

Технология базируется на использовании распределённой медиа-инфраструктуры звонков ВКонтакте (**VK Calls WebRTC / TURN Relays** — `calls.okcdn.ru`, `api.vk.me`). Клиент подключается к публичным релеям VK Calls в качестве анонимного участника группового звонка, инкапсулирует системный трафик в RTP-фреймы с криптографической маскировкой и передаёт его на собственный VPS-сервер. Для операторов связи и систем ТСПУ (DPI) такое соединение неотличимо от обычного голосового/видеозвонка внутри экосистемы VK.

```
[Пользовательские приложения]
             │
             ▼ (WinTUN / Linux TUN / Android VpnService)
   [NetTurn Client Core (Go)]
             │
             ▼ (RTP-obfs ChaCha20-Poly1305 AEAD / STUN-TURN Framing)
 [VK Calls TURN Relays (calls.okcdn.ru / 91.231.x.x, 90.156.x.x)]
             │
             ▼ (TURN UDP / TCP Data Channels)
     [NetTurn VPS Server]
             │
             ▼ (iptables NAT Masquerade)
       [Внешний Интернет]
```

## 🌟 Ключевые преимущества NetTurn

### 1. Высокопроизводительный движок RawTun (Zero-Overhead)
- **Прямая инкапсуляция IP-пакетов**: трафик из кольцевого буфера WinTUN (8 МБ) или дескриптора Android TUN сразу шифруется `ChaCha20-Poly1305 AEAD` с RTP-заголовком. Отсутствует двойное шифрование и оверхед WireGuard/DTLS.
- **Анти-джиттер диспетчеризация (Flow Dwell)**: алгоритм группировки пакетов одного размера в чанки и тайминг `maxDwellMS = 80ms` предотвращают разрыв порядка пакетов (TCP Out-of-Order) и коллапс окна `cwnd` в играх и мессенджерах.
- **Каскадное агрегирование потоков**: поддержка групп воркеров (кратных 9) с разделением пула аллокаций (`allocateGateInterval = 100ms`), что исключает получение ошибки `TURN 486 (Quota Exceeded)`.

### 2. Безупречная маршрутизация и устойчивость
- **Изоляция шлюза Windows**: определение физического маршрута по умолчанию через `Get-NetRoute`, создание строгих `/32` маршрутов до VPS и обнаруженных TURN-релеев VK, предотвращающее петли маршрутизации (Routing Loops).
- **Сетевой наблюдатель (Adaptive Sleep Mode)**: зондирование физического шлюза (TCP 53 к `77.88.8.8`). При смене сети (Wi-Fi ↔ LTE, выход из спящего режима ПК) клиент замораживает воркеры, обновляет маршруты к новому шлюзу и мгновенно возобновляет работу без разрыва сессии.
- **Интеллектуальный Bypass-движок**: математическое вычитание списков IP/сетей и доменов (с авто-резолвингом DNS) из глобального маршрута `0.0.0.0/0`.

### 3. Трехуровневое решение VK Smart Captcha
1. **Уровень 1 (Автономный Go)**: вычисление PoW (Proof of Work) и анализ непрерывности градиентов/текста для автосборки слайдер-пазла прямо в Go без запуска браузера.
2. **Уровень 2 (Headless WebView)**: эмуляция клика в скрытом контексте с рандомизацией User-Agent, Viewport и JS-перехватом `captchaNotRobot.check`.
3. **Уровень 3 (Интерактивный UI / Push)**: если VK требует прохождения интерактивного испытания, пользователю отправляется нативный push (на Android) или модальный оверлей (на Desktop) с возможностью решить капчу в один клик.

### 4. Встроенный сетевой мост (LAN Bridge & mDNS)
- **Единый порт (24066)**: поддержка как **SOCKS5**, так и **HTTP CONNECT** с автоматическим определением протокола по первому байту рукопожатия (`0x05` vs HTTP-метод).
- **Раздача на любые устройства**: мгновенное подключение смартфонов, Smart TV и консолей внутри домашней сети без установки клиентских программ.
- **Локальный mDNS / QR-код**: отображение понятного локального адреса (например, `pc-vpn.local:24066`) и QR-кода для быстрой настройки.

## 🎨 UX / UI Инновации

1. **Интерактивный конвейер подключения (Connection Pipeline)**:
   - Наглядная анимация прохождения фаз подключения в реальном времени:  
     `DNS` ➔ `VK API` ➔ `Smart Captcha` ➔ `WRAP (AEAD)` ➔ `TURN Relays` ➔ `Workers Init` ➔ `Virtual Adapter` ➔ `Tunnel Active`.
   - В случае ошибки пользователь сразу видит точный этап сбоя и подсказку по исправлению.

2. **Умный системный трей (Desktop)**:
   - Контекстное меню с мгновенным переключением `Включить / Выключить` в один клик без разворачивания главного окна.
   - Сворачивание при закрытии с чекбоксом «Запомнить выбор».
   - Индикация статуса туннеля цветом иконки в трее.

3. **Мониторинг сети в реальном времени**:
   - Живой график скорости приёма и отдачи (Kbps / Mbps).
   - Точный замер RTT (Ping) через туннель и до серверов VK.
   - Счётчики сессионного и пожизненного трафика.
   - Определение выходного IP и страны (GeoIP) с кнопкой проверки на утечки DNS.

4. **Пул звонков и валидатор ссылок**:
   - Менеджер нескольких VK-звонков для автоматического переключения при исчерпании лимитов.
   - Интерактивная кнопка **«⚡ Проверить звонки»** с параллельной диагностикой статуса каждого хеша.
   - Калькулятор воркеров с подсказками по кратностям и нагрузке на процессор.

5. **Встроенный мастер развертывания сервера (SSH Deployer)**:
   - Автоматическая настройка чистого VPS (Ubuntu/Debian/CentOS/Fedora) в пару кликов.
   - Интеграция с Telegram-ботом управления ключами и подписками.
   - Поддержка ссылок `qwdtt://`, `wdtt://` и удалённых URL-подписок.

## 📐 Архитектура системы

```
NetTurn/
├── core/                       # Ядро туннеля на Go (Shared Core Engine)
│   ├── engine.go               # Программный интерфейс (API запуска/останова/статуса)
│   ├── rawtun/                 # Высокоскоростной Raw-IP транспорт
│   │   ├── dispatcher.go       # Бондинг воркеров, балансировка и анти-джиттер
│   │   ├── tun_windows.go      # WinTUN драйвер, кольцевой буфер 8МБ, маршруты Windows
│   │   ├── tun_linux.go        # Linux TUN интерфейс
│   │   └── tun_darwin.go       # macOS utun интерфейс
│   ├── turn/                   # STUN/TURN протокол поверх Pion
│   │   ├── session.go          # Управление сессией TURN (UDP / TCP)
│   │   ├── group.go            # Группы по 9 воркеров и каскадное квантование
│   │   └── registry.go         # Реестр обнаруженных IP TURN для маршрутизации
│   ├── vk/                     # Взаимодействие с VK API и релеями OKCDN
│   │   ├── creds.go            # Получение токенов и кредов звонков
│   │   ├── hash_pool.go        # Пул хешей звонков, авторотация и healthcheck
│   │   └── captcha/            # Трехуровневый решатель капчи
│   │       ├── pow.go          # Proof of Work в Go
│   │       └── slider.go       # Анализ непрерывности пазлов
│   ├── bridge/                 # Локальный сетевой мост (PCVPN)
│   │   └── dual_proxy.go       # Автоопределение SOCKS5 + HTTP CONNECT (порт 24066)
│   ├── network/                # Сетевой мониторинг и устойчивость
│   │   ├── watcher.go          # Фоновый сетевой наблюдатель (Adaptive Sleep Mode)
│   │   ├── bypass.go           # Вычитание CIDR и доменный сплит-туннель
│   │   └── dns.go              # Защищённый DoH / системный DNS-резолвер
│   └── cmd/                    # CLI утилиты
│       ├── netturn-client/     # Консольный клиент
│       └── netturn-server/     # Серверная часть для VPS
│
├── desktop/                    # Десктопное приложение (Windows, macOS, Linux)
│   ├── main.go                 # Точка входа Wails v2 / Go GUI
│   ├── app.go                  # Биндинги ядра к интерфейсу
│   ├── tray.go                 # Нативный системный трей
│   └── frontend/               # UI интерфейс (HTML5, Modern CSS, TypeScript)
│
├── android/                    # Мобильное приложение (Android)
│   ├── app/src/main/kotlin/    # Jetpack Compose UI + VpnService
│   └── app/src/main/jniLibs/   # Скомпилированное Go-ядро
│
├── server/                     # Серверный компонент для VPS (wdtt-server)
│   ├── nat/                    # iptables MASQUERADE и TUN роутинг
│   ├── admin/                  # REST API администрирования
│   ├── bot/                    # Встроенный Telegram бот
│   └── deploy/                 # Автоматизированный bash-установщик (deploy.sh)
```
